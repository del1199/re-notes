Static Analysis

radare2 靜態分析與自動分析指令

快速掌握二進位執行檔載入、符號分析與函式反組譯核心指令。

一、核心分析指令對照

指令 完整含義 用途說明
aaa Analyze All Autoname 自動分析所有函式呼叫、交叉參照 (xrefs) 並為未命名函式自動命名。
afl Analyze Function List 列出目前二進位檔中所有已辨識的函式位址、大小與名稱。
pdf @ main Print Disassembly Function 反組譯並印出 main 函式的完整組合語言流程。

二、標準分析操作流程

$ r2 ./target_binary
[0x00401040]> aaa
[0x00401040]> afl
[0x00401040]> s main
[0x00401135]> pdf
實務提示：面對大型執行檔時，aaa 耗時較長；若僅需快速掃描基本呼叫關係，可改用層級較輕量的 aa。
